## 배포 중 발견하고 고친 것
1. Vercel Framework Preset이 Other → 전 페이지 500. `vercel.json` framework: nextjs (PR #19)
2. Claude 스트림 이중 close → Unhandled Rejection으로 함수 인스턴스 종료 (PR #21, 이슈 #20)
3. 빈 초안 일기를 다시 열면 초안을 만들 방법이 없음 → [초안 만들기] (PR #23, 이슈 #22)
4. 빈 채로 저장된 일기는 409 → 빈 일기는 재생성 허용 (PR #25, 이슈 #24)
5. 초안 실패 이유가 로그에 없음 → 로그 추가 (PR #26)
6. 대화가 질문으로 끝나면 실제 API가 400 (assistant prefill) → 마지막 user 턴 추가 (PR #27)
