## 확인 못 한 것
- 에이전트는 스크린샷 열람이 막혀 화면 텍스트로 판단함. 컨트롤러가 P2 모바일 스크린샷을 직접 확인: 테마 카드에 이름이 보이고(에이전트의 "가나다만 보임" 판단은 틀림), 선택기가 화면 상단 절반을 차지함(#3 확인), "대화 기록"은 맨 아래에 있음(#7).
- 중간 이탈 후 저장, 어제 일기 쓰기는 이번 흐름에서 시험하지 않음.

## 하네스 교훈
- 드라이버 버그 3개(세션 쿠키 미보존, 제목 칸 대신 라디오 선택, 라디오 클릭 가로막힘)로 1차 실행이 전부 중단됨 → 드라이버 자체를 먼저 스모크하고 돌릴 것.
- 페르소나 에이전트가 이미지를 못 보면 시각 항목(글씨 크기·색감)은 판단 불가 → 컨트롤러가 대표 스크린샷을 직접 확인해 보정.
